# 材料刷新计时（timers）

EndBox 的示例插件：记录采集点 / 材料刷新的倒计时。

## 功能

- 输入名称 + 选择时长（5 分钟 / 10 分钟 / 30 分钟 / 1 小时）开始计时；
- 多个计时可以并存，每个计时显示真实剩余时间（按系统时钟计算，不是 UI 计数）；
- **数据持久化**：计时写在插件私有存储 `%APPDATA%/EndBox/plugin_data/timers.json`，关掉程序再打开剩余时间仍然准确；
- **到点提示**：不管当前在哪个视图，右上角都会弹出「计时结束：名称」的提示；
- 删除单个计时（红色按钮，红色只用于删除）、清空已结束的计时。

## 用到的插件 API

| API | 用途 |
| --- | --- |
| `ctx.register_view(view_cls, sidebar_icon="clock", sidebar_label="计时", order=10)` | 注册「计时」视图，宿主自动加 `plugin_timers_` 前缀并放进侧边栏「插件」分区 |
| `ctx.storage.get()/set()` | 私有 JSON 持久化 |
| `ctx.notify(text, "warn")` | 全局 Toast 提示 |
| `QTimer`（插件自己持有） | 每秒检查到期，视图隐藏时也生效 |

manifest 里 `permissions` 是空数组：这个插件不需要读取账号或排轴数据。

## 试试看

1. 输入「采集点 A」，选 5 分钟，点「开始计时」；
2. 切到其他视图再切回来，剩余时间接着走；
3. 关闭 EndBox 再打开，「计时中」列表里还在；
4. 到点后看右上角提示。
