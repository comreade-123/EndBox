# 设计说明

## 变体卡

```
变体：夜班（黄 #FFFA00 / 中性纸 / standard 切角 / 等高线底纹 / compact 密度 / calm 动效），默认深色
主视觉：排轴时间轴 + 首次启动问候 + 干员编号墙（真实数据，不放假图表）
页面类型：主窗口壳是控制台；账号、设置页是阅读页
```

- 强调色：`#FFFA00`，只表示当前位置、可点击内容、醒目提醒，**只做填充**，黄底上写墨色。
- 纸色：深色 `#191919` / 浅色 `#F4F4F2`，深浅是两套完整主题，不是反色。
- 切角：内部可点击元素右下切角 8px，编号标签 6px；正文与不可点容器直角、圆角 0。
- 底纹：背景两角各一小片不闭合等高线（墨色 9%），空状态与标题带 45° 斜线纹。
- 密度：紧凑（导航 48px、行 38px、边距 16px）。
- 动效：出现 `snap`，擦入 / 退出 `mech`，单次 280–360ms；关闭动效时全部静止。

## 用户指定的偏差：窗口壳层圆角

要求.md 指定窗口参考 `窗口参考.png`，并在评审时补充"边框圆角，且侧边栏和主显示区分开，参考鹰角启动器"。因此：

- **窗口外框、侧边栏面板、主显示面板**使用圆角：整窗 16px、面板 12px，配 1px 细线与
  10px 间隙，毛玻璃从窗口边缘与间隙透出。
- 这一圆角**只属于壳层**；内部所有按钮仍是切角、正文容器仍是直角、没有任何投影 / 发光 / 渐变。

## 文案、确认与公式

- 全部界面文案集中在 `assets/text/zh-CN.json`，设置页可打开/重新加载；代码用 `endbox.core.text.t`。
- 所有删除/清空/重置走统一确认框 `endbox.ui.kit.confirm`：壳层圆角面板 + 切角按钮，红色只给删除，默认焦点在取消。
- 325 公式用 LaTeX 图形排版（matplotlib mathtext，vendored），不是原始文本。

## 应用图标与便携数据

- 图标来自用户提供的 `icon.png`（终末地同人插画），`tools/make_icon.py` 裁边缩放成
  `assets/branding/endbox.png`（512）与 `endbox.ico`（16–256 多尺寸）；用于窗口/任务栏、
  侧边栏字标、关于页。界面内部仍不使用游戏官方图标字体或标志。
- 便携模式：`userdata/`（settings / secure.dat / logs / plugins / timeline.json / timeline_library.json）
  跟随软件目录；旧 `%APPDATA%\EndBox` 首次启动自动迁移，程序目录不可写时回退。

## 字体

- Latin：Saira（宽体静态实例 `Saira Wide` 125%、`Saira Field` 112%、常规 100%），由
  `tools/make_fonts.py` 从可变字体切出，随包分发（OFL 1.1）。
- 中文：微软雅黑 UI（系统字体），通过 QFont 家族回退逐字混排。
- 数字：宽体等宽数字（`tnum`），所有数字都是真实计数 / 时间 / 进度。

## 首次启动问候

- 首次启动（`app.first_run=true`）或还没点开任何工具时，主窗口停在**首页**：
  `// WELCOME` + 大号问候「早上好，管理员」+「今天肝点什么？」+ 真实日期/时间/星期。
- 问候随时段变化：05 点早上、09 点上午、11 点中午、13 点下午、18 点晚上、23 点夜深了（深夜副标题提醒休息）。
- 名字取自绑定账号昵称；未绑定或演示数据时显示「管理员」（`endbox/core/greeting.py`，有单测）。
- 首页同时显示真实状态：排轴事件数、队伍人数、已绑定角色数、各模块连接状态、快捷操作。
- **每次打开 EndBox 都回到首页**（用户要求）：问候每次可见；点开工具仍会记录 `last_view`，但启动不恢复。

## 部件语汇

| 部件 | 实现 | 含义 |
| --- | --- | --- |
| 切角按钮 | `CutButton` | 可点击；悬停黄从左擦入，离开后退回；主按钮墨底 |
| 编号标签 | `Badge` | 墨底白字，右下切角；黄色 = 当前 |
| 字段 | `FieldText` | 宽体小字，`│` 分隔，全是真实数据 |
| 看板 | `Panel` + `NumberStat` | 细线面板 + 大数字 |
| 状态 | `Toggle` / `Status` 语义 | 实心 = 生效，虚线 = 未启用，黄色 = 需要注意 |
| 提示 | `InfoFlag` / `Toast` | 黄旗 + 墨线，不用红色 |
| 空状态 | `EmptyState` | 斜线纹带 + 一句完整的话 |
| 处理中 | `BusyBar` | 斜线纹扫过，完成后停 |

## 窗口与玻璃

毛玻璃用 **Windows 系统实时模糊**（`endbox/ui/glass.py::apply_acrylic`）：

1. 保留系统窗口样式，在 `WM_NCCALCSIZE` 里把标题栏与边框裁掉，客户区铺满整个窗口；
2. 用 `SetWindowCompositionAttribute` 开 acrylic：DWM 实时模糊桌面，拖动 / 换壁纸自动跟随；
3. 窗口四角交给 Windows 自己画圆角（系统样式保留），模糊一起被裁圆；
4. `paintEvent` 只叠一层很薄的纸色，面板半透明让模糊透出来；
5. 最大化时关闭模糊、取消圆角铺满；最大化 / 还原用单一进度动画；最小化渐隐、还原渐显（240ms）。

截图与自动化测试设 `ENDBOX_NO_GLASS=1` 关闭模糊，得到稳定背景。
