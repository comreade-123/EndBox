# 325 计算器

> 「325」是社区里的一个梗：不管怎么绕，最后都回到 325。
> 本模块参考同目录的参考项目 **Calculate325-main**，用纯 Python + `fractions.Fraction`
> 实现两个模式：**求解**（用数字串凑目标）与**随机**（种子 → 复杂算式，恒等于 325）。

## 1. 页面结构

- 顶部 `Segmented` 切换 **求解 / 随机**，默认记住上次模式（`calc325.mode`）；
- 求解模式：数字串凑目标，展示算式、块数、数字数、真实耗时，可复制 ASCII / LaTeX、切换多种写法；
- 随机模式：L1–L5 + 数字/Zc 种子，展示因子链、精确值，**LaTeX 用 `LaTeXView` 实时刻录成图形**
  （matplotlib mathtext；失败才退回文本），可复制/收藏/保存 PNG；
- 所有界面文案集中在 `assets/text/zh-CN.json` 的 `calc325` section（`from endbox.core.text import t`）；
- 数据（历史、收藏）写在 `config.DATA_DIR`（默认 `%APPDATA%/EndBox`）：
  `calc325_history.json`、`calc325_favorites.json`，各最多 100 条；清空/删除/取消收藏前一律先弹确认框（`from endbox.ui.kit import confirm`）。

## 2. 求解模式（区间 DP）

规则与参考项目 `src/solver.js` 一致：

- **目标**：整数 / 小数 / 负数（如 `325`、`1000`、`3.25`、`-7`）；
- **数字串**：内置 `325 / 799 / 325799 / 114514`，也可自定义 1–8 位（不以 0 开头），
  或「我全都要」（依次尝试四个内置串，取第一个成功结果）；
- **最多块数** 1–6：数字串重复 k 次后，数字之间可插 `+ − × ÷` 与括号，
  相邻不插运算符就拼成多位数；
- **顺序**：固定（`325325…`）或任意换序（只要求字符多重集相同）；
- **可选运算**：后缀阶乘（上限 3/5/8/12）、小数点；
- **高级运算**（对应参考项目的高级开关子集）：乘方 `a^b`、根号 `sqrt()`、
  组合数 `comb(n,k)`、`gcd()/mod()`；
- **时间预算** 2/5/8 秒；超时与无解给出人话提示。

算法（参考 `solver.js` 的区间 DP + 按 token 数分轮）：

```
dp(子串, t) = 用这段数字、恰好 t 个「数」能算出的全部精确有理数
t = 1：整段作为一个数（整数，或任意位置插小数点）
t ≥ 2：切成 a|b，取 dp(a, i) × dp(b, t-i) 做二元运算
块数 k 由小到大、每块内 t 由小到大构建，命中即停 → 先得到块数/token 最少的写法
```

- 数值全程 `Fraction`，无浮点误差；乘方/根号/组合数/gcd·mod 也在 DP 内精确计算；
- 每轮每子串有容量上限（`class_caps`），并有数值/分母上限与时间预算，防止搜索爆炸；
- **独立复算**：找到结果后，用 `ast_eval` 这个独立递归下降解析器重新解析打印出来的
  ASCII 算式并精确求值，同时检查数字顺序/数量；两者都通过才返回 `verified=True`。
  例如「325 凑 1000」会得到 `325×3+25`（2 块、3 个数字、通常几百毫秒）。

## 3. 随机模式（L1–L5）

| 等级 | 种子十进制长度 | 内容 | 嵌套深度（实测断言） |
| --- | --- | --- | --- |
| L1 | 12 位 | 只有 + − × ÷ 与括号 | 0 |
| L2 | 20 位 | 单层积分 / 无穷级数 / 极限 | 1 |
| L3 | 24 位 | 固定 4 层嵌套 + 恒等陷阱 | 4 |
| L4 | 32 位 | 5–9 层嵌套、多重积分、级数重排 | 5–9 |
| L5 | 64 位 | 10+ 层嵌套、矩阵行列式、数论函数 | 10–12 |

- 一条算式 = 若干**因子**相乘，每个因子带精确 `Fraction` 值，乘积严格 = 325；
- 因子分三类：
  1. **核心因子**：把 5、13 这类显眼常数藏进经典模块 ——
     `∫₀¹(4x+3)dx`、`Σₖ₌₀^∞(4/5)ᵏ`、`limₙ→∞(5n+3)/(n+1)`、复数模长 `|3+4i|`、
     部分和 `Σₖ₌₀²3ᵏ`；
  2. **陷阱层**：值恒等于 1 的可验证变形 —— 伸缩级数 `Σ 1/(n(n+1))`、
     `Σ 2⁻ⁿ`、恒等极限、`∫₀¹2x dx`、`2·Σₙ₌₂^∞2⁻ⁿ`、嵌套积分、嵌套极限、行列式；
  3. **L4/L5 专属**：多重积分、级数重排、`det` 矩阵、`τ(2¹²)=13`、`φ(11)/2=5`、
     `Σ(d|12)φ(d)/12=1`、10+ 层嵌套积分；
- L1 不使用积分/级数/极限，只允许四则运算；L3+ 可出现乘方/阶乘/小数形式的恒等陷阱；
- **禁止**裸 325 / 650 / 13·25 之类的写法（测试逐条断言）；
- **独立复算**：生成后把因子精确值组成 ASCII 表达式，交给 `ast_eval` 重新解析求值，
  必须 = 325；每个因子的 `meta` 还会在测试里被独立实现（积分、级数、行列式、数论函数、
  嵌套积分各写一套）重新验证，避免「生成器自己说自己对」。

### 种子类型

两种编码是同一个种子的不同写法（`SeedDialog.cs` 的思路）：

- **纯数字**：按等级固定长度的十进制串（首位 1–9），输入后每 4 位分组预览；
- **Zc 模式**：把十进制种子转成二进制，再按位置交替写 `Z`、`C`（大写=1、小写=0）。
  例如 `ZcZcZc` → `101010` → 42。输入必须满足字母交替；非法输入即时提示；
- 「随机种子」按等级生成合规种子；「复制种子」输出每 4 位一组、每 32 位换行的格式；
- 同一个种子 + 同一等级永远得到同一条算式，且数字种子与它的 Zc 写法生成结果完全一致。

## 4. 历史与收藏

- 每次随机生成自动写入历史（同种子+等级去重并移到最前，最多 100 条）；
- 历史支持按等级筛选、点击恢复（等级/种子类型/种子一起恢复）、删除单条、清空；
- 收藏最多 100 条，按 LaTeX 去重，可收藏/取消/点击查看/清空；
- **删除类操作全部先确认**：清空历史、删除单条历史、取消收藏、清空收藏都会弹 `confirm(...)`
  确认框（默认焦点在取消，Esc 取消）；确认文案在 `calc325.history.confirm.*` / `calc325.favorites.confirm.*`；
- 写盘使用临时文件 + `os.replace` 原子写；JSON 损坏时按空列表处理，不阻塞界面；
- 求解结果不写入历史（历史属于随机模式，与参考项目一致）。

## 5. 实时排版 / PNG / 快捷键

- 随机模式：**LaTeX 实时排版**——等级/种子类型/种子（防抖后）/生成按钮/历史恢复都会立刻重建
  `LaTeXView`（逐个因子一行，mathtext 图形；渲染失败自动退回文本）；
- 求解模式：结果默认用 `LaTeXView` 排版，可切到「纯文本」查看 ASCII；复制按钮分别复制 ASCII / LaTeX；
- 复制：随机模式可复制算式（Unicode 文本）、LaTeX、种子（分组格式）；求解模式可复制 ASCII / LaTeX；
- 保存 PNG：把当前随机算式的 `LaTeXView` 渲染图 + 标题、等级/种子、因子精确值、大号「= 325」合成；
- 快捷键（仅视图聚焦时生效）：`Ctrl+Enter` 重新生成 / 重新求解，`Ctrl+R` 换随机种子。

## 7. 与参考项目 Calculate325-main 的对照

| 参考项目 | 本实现 | 差异 / 说明 |
| --- | --- | --- |
| 求解：目标 + 数字串 + 块数 + fixed/any、阶乘/小数 | ✅ 全部实现 | 高级运算为子集：乘方/根号/组合数/gcd·mod（参考项目的行列式求解器未做进求解模式） |

| 随机 L1–L5（12/20/24/32/64 位种子） | ✅ | L5 按要求实现 10+ 层 + 矩阵/数论 |
| Zc 编码（Z/C 交替、大小写=0/1） | ✅ | 与参考项目一致；Zc 是十进制种子的另一种写法 |
| 历史 300 条 / 收藏 300 条 | ✅ 各 100 条 | 上限按本任务要求 |
| 4 套皮肤、WPFMath 排版、滚轮缩放/拖动/导出大图 | 部分实现 | 沿用 EndBox 深浅主题；用 `LaTeXView`（matplotlib mathtext）实时排版成图形，不支持矩阵环境（行列式改写为展开式）；PNG 由渲染图合成，不是 WPFMath 的缩放/平移导图 |
| 自定义种子窗口、单条查看窗口、收藏夹批量操作 | 部分实现 | 种子直接在页面输入；历史/收藏行点击恢复；未做独立查看窗口与批量勾选 |
| 结构化保底构造（n = P×q + r 递归） | ❌ 未实现 | 搜索超时/无解直接提示调大块数/预算，不伪造结果 |
| 求解「我全都要」 | ✅ 依次尝试四个内置串取首个成功 | 参考项目中是分模式求解；本实现只展示第一个成功结果 |

## 8. 已知限制

- 求解器是「搜索 + 命中即停」，不保证任意目标在预算内一定有解；无解/超时时不会构造保底算式；
- 随机模式的经典模块值（积分/级数/极限的闭式值）由模块定义给出，测试侧用独立实现
  （积分公式、部分和、Laplace 行列式、欧拉 φ 定义、嵌套积分阶乘公式）复算；
  不是 CAS 符号证明，也不涉及 π、e 等无理数；
- 随机模式为保证精确有理数，只使用有理闭式的积分/级数/极限，没有 Wallis 乘积等含 π 的模块；
- PNG 由 QPainter 合成「标题 + LaTeXView 渲染图 + 精确值 + = 325」，不是完整 TeX 排版；
  单条公式过长时会按因子逐行渲染（mathtext 不支持自动换行）；
- 求解结果不写历史；历史/收藏上限 100 条，跨设备不同步；
- 参考项目 README 说明其多数内容由 DSH 生成——本项目仅参考其**设计与算法思路**，代码为独立 Python 实现。
